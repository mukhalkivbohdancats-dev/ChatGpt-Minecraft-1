# BlockWorld

A small Android voxel sandbox built with Kotlin and OpenGL ES 2.0.

## Features
- Procedurally generated block terrain
- First-person camera with touch-look controls
- On-screen movement controls
- Break and place blocks
- Local world persistence
- Android APK build with GitHub Actions

## Build
Push to `main` or run the **Android APK** workflow manually. The workflow builds a debug APK and uploads it as an artifact.

## Requirements
- Android 7.0 (API 24) or newer
- OpenGL ES 2.0 capable device

## Project
The app is native Android/Kotlin. It does not use Minecraft assets, code, or trademarks.
